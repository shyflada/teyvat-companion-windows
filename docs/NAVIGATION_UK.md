# Teyvat Companion для Windows

1. Завантаж ZIP зі сторінки [Releases](../../../releases), розпакуй його й запусти `TeyvatCompanion.exe`. Зберігай DLL поруч із програмою.
2. Запусти Genshin Impact у вікні або без рамок. У Teyvat Companion вибери регіон за потреби й натисни **Start navigation**.
3. Повернися в гру. Якщо компас загубив позицію, ненадовго відкрий карту **M** із видимою синьою міткою персонажа.
4. Компас реагує на поворот камери. Після розпізнаного відкриття програма сама переходить до наступної цілі. **F8** позначає поточний сундук вручну, **Ctrl+Alt+N** пропускає його.

У **Settings → Language** можна вибрати українську або російську. У **Settings → Connect HoYoLAB** увійди на офіційній карті, щоб синхронізувати зібрані мітки.

Під час оновлення заміни файли програми. Прогрес зберігається окремо у `%LOCALAPPDATA%\TeyvatCompanion`. Резервну копію можна зробити через **Advanced tools → Backup database**.

Відстань на компасі приблизна й горизонтальна. Робота під землею залежить від рівня карти. [Збірка з коду](BUILD.md) · [Приватність](../PRIVACY.md)
