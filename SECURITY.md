# Security

Report suspected vulnerabilities privately to the project maintainer. Include the
affected version and reproduction steps using a fresh test profile. Keep account
credentials, game IDs, recordings and application data out of issue attachments.

The app uses HTTPS for official map data and restricts account writes to the
official map UI with exact map and marker checks. Local changes remain queued
until HoYoLAB acknowledges them. See [privacy details](PRIVACY.md).
